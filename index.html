Features

Everything a new project needs on day one

Backbone is the front door to a tested build system. It removes the blank page and the guesswork, and keeps the rules that stop projects going wrong.

Plan any idea

Type the idea in plain words. Backbone suggests the best platforms and the features people will expect, from booking forms to offline guides.

A real foundation

Every project starts from a template that is already built and tested: website, phone app, offline app, private data engine or game.

Live preview

See how the first screen could look before any code is written, in a clean, bright style that suits a real business.

A ready-to-build brief

One tap writes a clear brief: what to build, which template, which features and which rules. Hand it straight to your developer or AI assistant.

Live prices and alerts

A watch list that refreshes every 15 minutes, even with the app closed, and a notification when a price moves past your line.

Home-screen widget

Your watch list on the home screen at a glance. Tap it to open the app on the right screen.

How it works

Four steps from idea to a working start

  1. Describe it

    Say what you want to make and who it is for. Pick from ready examples if you prefer.

  2. Pick the foundation

    Backbone matches the idea to the right tested template and the features it needs.

  3. Preview it

    Check the look and the first screen. Change the name, colours and words in seconds.

  4. Start the build

    Take the brief to your build tools. Every build is checked for keys and errors before it can go anywhere.

Privacy and safety

Built to be trusted

The rules are part of the system, not a promise on a page. Builds stop themselves if a rule would be broken.

No account, no tracking

No sign-up, no ads, no analytics. The app reads one public file and nothing else leaves your phone.

Secrets never ship

Every build and every file shared is scanned for keys and passwords, and it is blocked if one is found.

Private stays private

Source code and data engines stay on your own computer. Only the finished result is ever published.

FAQ

Questions

Is Backbone free?

Yes. The app is free, with no ads and no in-app purchases. The build system behind it uses free tools only.

Why isn't it on Google Play yet?

It is installed directly from this page for now. The file is signed, so later versions install over the top and keep your settings.

Is there an iPhone version?

Not yet. Backbone can plan iPhone apps, but the app itself is Android only for now.

Why do alerts need the battery setting?

Android can pause background checks to save power. Lifting the limit for Backbone lets the 15-minute price check keep running. You can change it back at any time.

Is the market data advice?

No. The prices are information only, not financial advice. Always do your own research.

What does Backbone collect about me?

Nothing. There is no account, and your ideas and watch list stay on your phone. See the privacy page.
