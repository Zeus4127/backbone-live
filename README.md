# Backbone live feed

This is the public feed and the Android download for the Backbone app.

- **Get the app (Android):** https://github.com/Zeus4127/backbone-live/releases/latest/download/Backbone.apk
  Open the link on your phone, tap the file, and allow "Install unknown apps" if asked. It installs over older versions.
- **Live feed:** [`live.json`](live.json). The app reads this file for prices. It holds finished daily closes for 5 coins from public market data, with no keys and no private data.

## New in v2.2
A **Turn on alerts** panel opens the first time you open the app. Tap **Fix** on anything that isn't ticked, then tap **Send test alert**. To open it again later, long-press the app icon and choose "Turn on alerts".
